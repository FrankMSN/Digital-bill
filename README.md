# Smart POS & Smart Note (Offline-First POS & Dual Google Sheets Sync)

ระบบจัดการบิลหน้าร้าน บันทึกเซ็นเชื่อ (IOU) สแกนแยกแยะสินค้า/อาหารด้วยกล้อง AI และเชื่อมต่อซิงค์ 2 ตารางกับ Google Sheets แบบ Offline-First 100%

## 📊 ระบบเชื่อมต่อ Google Sheets 2 ตาราง (Dual-Table Integration)

ระบบโหลดราคาและข้อมูลสินค้าจาก **Google Sheets** โดยแยกเป็น 2 ตารางอย่างชัดเจน:

### 1. ตารางสินค้าปลีก (`สินค้า_SmartPOS`)
- **วัตถุประสงค์**: จัดเก็บรายการสินค้าขายปลีกสำหรับ **บิลร้านค้า (Retail)** และการตรวจจับสินค้าด้วย **กล้อง AI OCR**
- **คอลัมน์**: `รหัสสินค้า (ID)`, `ชื่อสินค้า (Name)`, `ราคาขาย (Price)`, `หมวดหมู่ (Category)`, `คีย์เวิร์ด AI/OCR (Keywords)`, `ลิงก์รูปภาพ (Image URL)`, `บาร์โค้ด (Barcode)`

### 2. ตารางเมนูอาหาร (`อาหาร_SmartPOS`)
- **วัตถุประสงค์**: จัดเก็บรายการเมนูอาหารตามสั่งสำหรับ **บิลร้านอาหาร (Restaurant)** และการตรวจจับอาหารด้วย **กล้อง AI OCR**
- **คอลัมน์**: `รหัสเมนู (Food ID)`, `ชื่อเมนูอาหาร (Name)`, `ราคา (Price)`, `หมวดหมู่ (Category)`, `คีย์เวิร์ดค้นหา (Keywords)`, `ลิงก์รูปภาพ (Image URL)`

### 3. ตารางบันทึกบิลแยกตามประเภท:
- **`บิลร้านค้า_SmartPOS`**: บันทึกบิลขายสินค้าปลีก
- **`บิลร้านอาหาร_SmartPOS`**: บันทึกบิลร้านอาหารตามสั่ง

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

### 1. เปิดเซิร์ฟเวอร์จำลองในเครื่อง (Local Dev Server)
รันคำสั่ง:
```bash
node server.js
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3000/`

### 2. เชื่อมต่อ Google Sheets (ทำครั้งเดียว)
1. ไปที่ [Google Sheets](https://sheets.google.com) สร้างสเปรดชีตใหม่
2. คลิกเมนู **ส่วนขยาย (Extensions)** ➔ **Apps Script**
3. ลบโค้ดเดิมทั้งหมดในไฟล์ `Code.gs` แล้วนำโค้ดจาก `js/google_apps_script.js` (หรือกดปุ่มคัดลอกในหน้าเว็บ) ไปวาง
4. กด **บันทึก (Ctrl+S)**
5. คลิก **การทำให้ใช้งานได้ (Deploy)** ➔ **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ชนิด: **เว็บแอป (Web app)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. คัดลอก **URL เว็บแอป (Web app URL)** นำมาวางในหน้าต่าง **"Google Sheets"** บนหน้าเว็บ Smart POS
7. กด **"ทดสอบการเชื่อมต่อ"** ➔ ระบบจะสร้างตาราง `สินค้า_SmartPOS` และ `อาหาร_SmartPOS` พร้อมเติมข้อมูลเริ่มต้นให้อัตโนมัติทันที!

## 🔒 จุดเด่นด้านความปลอดภัยและเสถียรภาพ (Offline-First)

- **Offline-First Cache**: ข้อมูลราคาสินค้าและอาหารจะถูกแคชไว้ใน `localStorage` ของเครื่องทันที ทำให้แม้ไม่มีอินเทอร์เน็ต แอปก็ยังเปิดใช้งานและคิดเงินได้ตามปกติ
- **Strict Price Snapshot Guarantee**: เมื่อเพิ่มสินค้าลงในบิล ราคาจะถูกล็อกลงในฐานข้อมูล IndexedDB ในเครื่องทันที การเปลี่ยนแปลงราคาใน Google Sheets ภายหลังจะไม่ส่งผลกระทบต่อบิลย้อนหลัง
